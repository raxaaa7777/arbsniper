# Запуск и проверка ArbSniper (Windows / macOS)

Инструкция для машины с домашним интернетом. Всё, что отмечено «ожидал», —
проверено в песочнице на веб-превью (`download/arbsniper-preview.html`,
движок и UI идентичны), кроме пунктов, где явно сказано «только десктоп».

## 1. Подготовка (один раз)

### Windows 10/11

1. **Rust**: https://rustup.rs → скачай `rustup-init.exe`, установи (default).
2. **MSVC**: Visual Studio Build Tools 2022 → workload «Desktop development with C++»
   (https://tauri.app/start/prerequisites/#microsoft-c-build-tools-visual-studio-build-tools).
3. **WebView2**: на Win10/11 уже предустановлен; иначе — ссылка с той же страницы.
4. **Node 20+** (для npm-варианта CLI, необязательно — см. ниже).

### macOS

1. `xcode-select --install`
2. Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
3. Apple Silicon: бинарь соберётся под arm64 нативно.

### Общее

CLI Tauri 2 (выбери ОДИН вариант, иначе команды из README не совпадут):

```bash
cargo install tauri-cli --version "^2.0.0"   # тогда работают: cargo tauri dev / build
# ЛИБО npm install -g @tauri-apps/cli@^2      # тогда команды: tauri dev / tauri build
```

В README/package.json скрипты зовут `cargo tauri` — под этот вариант ставь
`cargo install tauri-cli`.

## 2. Запуск

```bash
cd arbsniper
cargo tauri dev     # dev-режим: окно откроется сразу, логи в терминале
```

Первая сборка — 5–10 минут (компилируется Tauri). Дальше — секунды.

## 3. Готовый установщик

```bash
cargo tauri build
```

Готовые файлы:

- Windows: `src-tauri/target/release/bundle/nsis/ArbSniper_0.1.0_x64-setup.exe`
- macOS: `src-tauri/target/release/bundle/dmg/ArbSniper_0.1.0_aarch64.dmg`

Тонкий бинарь (LTO + strip) — Release-профиль уже настроен в `Cargo.toml`.
DMG не подписан: при первом открытии правый клик → «Открыть».

## 4. Чек-лист проверок (10 минут)

### Радар (вкладка 1, Demo по умолчанию)

- [ ] **Спот в шапке живой**: число меняется с меткой «живой · Binance» —
      обновляется каждые 30 сек. Если Binance недоступен — фолбэк CoinGecko.
- [ ] **Окна спреда появляются**: 2 строки «Binance P2P (demo) → Bybit P2P (demo)»
      с ~+2% и суммой в RUB; значения слегка дрожат каждые 3 сек (тик).
- [ ] **Живое окно**: зелёный баннер «ЖИВОЕ ОКНО» сверху + строка в журнале
      (вкладка 2) + короткий beep при появлении.
- [ ] **Витрины**: у каждой биржи книги buy и sell по 3 строки, цены в RUB,
      способы оплаты (Tinkoff/Sber/SBP) видны.

### Калькулятор (вкладка 2, значения по умолчанию)

- [ ] Поля 90.00 / 92.00 / 1000 / 0.2 → ожидал:
      валовый **+2.22%**, чистый **+2.02%**, фиат **90 000 RUB**,
      чистая прибыль **+1 820 RUB на круг**. Пересчёт мгновенный при вводе.
- [ ] Поменяй цены местами (92 → 90) — красная **отрицательная** чистая
      прибыль: минус считается так же честно.

### Настройки (вкладка 3)

- [ ] Порог сигнала 1.5% → поставь 5% — баннер и окна должны пропасть
      (ниже порога), вернуть 1.5% — снова живые.
- [ ] Период скана 3 → 10 сек: тик окон реже ровно в той же пропорции.
- [ ] Порог Live (тумблер на радаре): витрины станут пустыми с пометкой
      «нет данных» — **из облачных/VPN-сетей это норма (WAF)**. С домашнего IP
      ожидание: реальные объявления Binance/Bybit и окна по ним.
- [ ] RU/EN в шапке: все подписи переводятся, инпуты НЕ исчезают.

### Только десктоп (в превью отсутствуют)

- [ ] **Трей**: иконка с числом живых окон; клик — свернуть/развернуть.
- [ ] **Alt+S** скрывает/показывает окно из любого места.
- [ ] **Нативное уведомление** OS при живом окне (если включено в системе).

### Данные и математика

- [ ] Журнал копится, записи с временем и % — не перезатираются.
- [ ] Переключение фиата RUB → USD: спот-ориентир пересчитывается,
      книги остаются в выбранной валюте (числа обновятся).

## 5. Если что-то не так

| Симптом | Причина / решение |
| --- | --- |
| `link.exe not found` (Win) | Не установлены VS Build Tools с C++ workload — см. п.1. |
| `cargo tauri: command not found` | CLI не установлен: `cargo install tauri-cli --version "^2.0.0"` (или используй `npx tauri dev`). |
| Live-витрины пустые | WAF: отключи VPN/прокси; работает только с «жилых» IP. Спот и Demo работают всегда. |
| Первая сборка «зависла» | Норма: Tauri компилируется 5–10 мин, прогресс в терминале. |
| Окно не реагирует | `cargo tauri dev` показывает логи движка в терминале — пришли их автору. |
