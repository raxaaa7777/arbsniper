# Roadmap ArbSniper

## v0.1 — MVP (этот код)

- [x] Радар: фоновый цикл (30 с по умолчанию), книги обеих сторон, живые окна
- [x] Фетчеры Binance P2P + Bybit P2P (документированные эндпоинты) + demo-источник
- [x] Спот-ориентир USDTRUB (Binance → фолбэк CoinGecko)
- [x] Калькулятор сделки: чистый спред, потребный фиат, прибыль
- [x] Журнал сигналов, трей-бейдж живых окон, Alt+S
- [x] RU/EN, тёмный неон, локальный JSON-стор

## v0.2 — больше глаз и глубина

- [ ] OKX P2P и HTX: третья-четвёртая витрина (эндпоинты известны, нужен парсинг)
- [ ] Углубление книги: агрегация top-3 заявок с учётом объёмов (сейчас — лучший прайс)
- [ ] История спреда по парам: мини-график «сколько жило окно»

- [ ] PWA-компаньон: те же окна в браузере телефона (лид-магнит к десктопу)

## v0.3 — Pro-тир (монетизация)

- [ ] Хранение таргет-портфеля: сколько USDT/фиата в обороте, счётчик кругов
- [ ] Учёт P&L: отметки «взял/упустил» по сигналам, статистика доли взятых
- [ ] Автоскан глубины: алерты по «появился объём 10k+ по обеим сторонам»
- [ ] Telegram-бот: пересылка живых окон на телефон (по ключу юзера)
- [ ] iCloud-синхронизация настроек между компами (opt-in, явно)

## Монетизация

- **Free:** навсегда — радар 2 бирж, калькулятор, журнал. Виральность важнее
  раннего ARPU: каждый пользователь — источник данных о том, какие окна реально
  закрываются.
- **Pro ($9/мес или 5 USDT/мес, криптооплата):** 4+ витрины, история спредов,
  P&L-учёт, Telegram-алерты, фильтры платёжек. Целевая аудитория: P2P-мерчанты и
  арбитражники, у которых цена вопроса — один взятый круг в месяц.
- **Принцип:** не продаём сигналы «с гарантией» (см. STRATEGY.md — риски честно),
  продаём скорость и учёт. Инструмент снайпера, а не «кнопка деньги».

## Не в планах (принципы)

- Автоторговля/автопереводы — никогда: риск фиата на чужой счёт нельзя
  перекладывать на софт.
- Хранение ключей/средств — никогда.
- Закрытый код — нет: MIT.
